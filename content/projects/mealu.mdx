MealU is a full-stack meal kit ordering platform built mobile-first for university students. The backend runs Django REST Framework with PostgreSQL and AWS for storage and compute; the frontend is React wrapped in Ionic for a native-feeling mobile experience across platforms.

The core innovation is contactless pickup: a QR-based locker system replaces traditional delivery runs, cutting overhead and adding security. I added community features too — recipe sharing, peer reviews, and a credit-based reward system to drive engagement and repeat orders.
