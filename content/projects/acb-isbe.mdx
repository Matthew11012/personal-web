ACB-ISBE is a web and mobile app for an international conference with over 1,600 participants. I built it in Flutter to deliver a responsive experience on both platforms from a single codebase, using a shared API for schedules, speaker information, and event data.

The unified experience meant attendees didn’t have to learn two different interfaces — the web and mobile versions felt like the same product, just reshaped for the device. That consistency mattered at an event that size.
